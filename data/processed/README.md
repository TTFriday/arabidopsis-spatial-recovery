# Processed inputs

These files are the inputs to the archived experiments:

- `adata_processed.h5ad` - concatenated log1p expression matrix and spot metadata
  for the ten samples.
- `spatial_edges.csv` - directed per-sample 6-nearest-neighbour edges with
  distances.
- `data_splits.json` - boolean train/validation/test masks over spots.
- `metadata.json` - sample identifiers, dimensions, cell types, and edge count.

They were generated by `preprocess_data.py` from the deposited H5AD files. See the
repository README for the data source and the preprocessing caveats.
